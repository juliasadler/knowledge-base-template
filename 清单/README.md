# 清单/

审计与体检清单的存放区。**只记录状态与结论，不存正文**。

## 建议的清单文件

| 文件 | 内容 |
|---|---|
| 来源清单.md | 一行一个来源：名称、类型、地址、备注、可信度 |
| 收件登记.md | 一行一条收件：日期、标题、来源、类型（入库SOP第一步） |
| 语料完整性审计.md | 定期抽查：文件是否都在、命名是否合规 |
| 补齐清单.md | 缺失语料的待办事项：缺什么、去哪补、截止日期 |
| 入库检查-YYYYMMDD.md | 每次入库的检查表归档（从 `模板/入库检查表-模板.md` 复制） |

## 规则

- 清单只记状态，不复制正文（正文在 `原文语料/` 或 `知识库/`）
- 审计发现问题要排期修复，修复后在清单里闭环
