# 原子条目规范

## 什么是原子

一条**独立、完整、可复用**的知识单元。判断标准：单独拎出来看，
不需要依赖上下文也能理解；再拆就会碎。

- ✅ 原子："定投分批买入可以平滑成本"（独立完整）
- ❌ 非原子："他还说了定投的事"（依赖上下文，不知"他"是谁）

## ID 格式

`KB-A-0001`：前缀 KB-A ＋ 4 位序号，按入库顺序递增，**一经分配永不复用**。
删除原子时 ID 作废不回收，映射表留一行注明"已删除"。

## 原子字段

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | KB-A-xxxx |
| 标题 | 是 | 一句话，不超过 20 字 |
| 摘要 | 是 | 50 字以内说清这条知识 |
| 正文 | 是 | 完整表述，可多段 |
| 来源 | 是 | 来源标注（`规则/来源标注规范.md`） |
| 标签 | 否 | 从主题词里选 |
| 概念 | 否 | 挂接到概念索引的条目 |
| 创建日期 | 是 | YYYY-MM-DD |
| 版本 | 是 | 新建为 1，修订 ＋1 |

## 映射表

`索引与维护/原子映射表.md` 记录**原子 ↔ 来源**的对应关系：

| 原子ID | 标题 | 来源文件 | 来源位置 | 状态 |
|---|---|---|---|---|
| KB-A-0001 | 示例 | 原文语料/article__example-blog__2026-01-01.txt | 第3节 | active |

- 来源位置精确到章节/页码/时间戳，精确到能直接翻到的程度。
- 一条原子可对应多个来源（多源印证时逐行列出）。

## 修订规则

- 修订原子 = 新建版本行（旧版本保留），`version` ＋1，更新日志记一笔。
- 禁止原地改写后不留痕：任何修改必须可追溯。
- 两个来源对同一原子的表述矛盾：不合并，各自保留并标注来源。

## 引用规范

文档中引用原子写 `KB-A-0001`，渲染/阅读时可展开为"标题（KB-A-0001）"。
禁止只写标题不写 ID（标题可能重复，ID 唯一）。
