# 来源标注规范

## 铁律

**每条知识必须能追溯到原文文件。** 无来源的条目不许入库（入库SOP质量门③）。

## 标注格式

| 场景 | 格式 | 示例 |
|---|---|---|
| 引用语料文件 | 【来源：文件名】 | 【来源：article__example-blog__2026-01-01.txt】 |
| 精确到位置 | 【来源：文件名/章节或页码】 | 【来源：article__example-blog__2026-01-01.txt/第3节】 |
| 引用原子 | 原子ID | KB-A-0001 |
| 多源印证 | 逐个列出 | 【来源：a.txt/第2节；b.txt/第5节】 |
| 备选库来源 | 【备选库·来源：文件名】 | 【备选库·来源：notes__example-forum__2026-03-15.txt】 |

## 转述与原文引用

- **原文引用**：用引用块 `>` 包裹，一字不改，并标注来源。
- **转述**：用自己的话重写，句末标注来源。
- 两者不得混淆：转述里夹原文句子而不加引用块，视为违规。

## 在提炼文档中的位置

- 每个原子条目的"来源"字段必填（`规则/原子条目规范.md`）。
- 文档末尾设"来源清单"节，汇总本篇用到的全部语料文件。
- 概念索引的"出处"列同样执行本规范。

## 禁止事项

- 禁止"据某文章"这种模糊标注：必须精确到文件名。
- 禁止来源标注指向备用库却不带【备选库】说明。
- 禁止事后补标注：提炼时当场标注，事后补的一律视为可疑条目重审。
