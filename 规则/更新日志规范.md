# 更新日志规范

## 位置与格式

- 文件：`索引与维护/更新日志.md`（从 `模板/更新日志-模板.md` 复制）。
- 按日期分节，**倒序**排列（最新的一节在最上面）。
- 每节结构：

```markdown
## YYYY-MM-DD

### 新增
- KB-A-0001 示例原子标题（来源：article__example-blog__2026-01-01.txt）

### 修订
- KB-A-0002 标题：修订说明

### 转正
- example-forum：3 篇语料转正

### 审计
- 语料完整性抽查：20 个文件全在；索引对账：无断裂
```

## 变更类型

| 类型 | 何时用 |
|---|---|
| 新增 | 新原子/新文档入库 |
| 修订 | 原子或文档内容修订 |
| 转正 | 备用库来源转正 |
| 审计 | 定期体检结论 |
| 修复 | 索引断裂、命名违规等问题的修复 |
| 建库 | 第一节，记录建库日期与初始来源 |

## 维护约定

1. 每次入库、转正、审计后**必须**记一笔，无例外。
2. 只追加新节，**绝不修改**历史章节（写错了在新节里更正）。
3. 每节条目写清关联的原子ID/文档ID，方便回查。
4. 每月复盘时通读本月各节，确认无遗漏。

## 禁止事项

- 禁止把更新日志当正文写：只记"发生了什么变更"，不记知识内容。
- 禁止合并日期节：一天一节，当天多次变更写进同一节。
