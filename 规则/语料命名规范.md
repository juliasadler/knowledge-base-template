# 语料命名规范

## 格式

```
{类型}__{来源}__{日期}[__{序号}].txt
```

双下划线 `__` 是分隔符，三个字段缺一不可。

## 字段定义

| 字段 | 取值 | 说明 |
|---|---|---|
| 类型 | article / notes / book / video / audio / image | 文章/笔记/书籍/视频转写/音频转写/图片说明 |
| 来源 | 英文小写短横线 | 如 `example-blog`；新来源先登记到 `清单/来源清单.md` |
| 日期 | YYYY-MM-DD | 材料本身的日期，不是入库日期 |
| 序号 | 01、02… | 同一来源同一天多篇时追加，平时省略 |

## 示例

```
原文语料/article__example-blog__2026-01-01.txt
原文语料/notes__example-forum__2026-03-15.txt
原文语料/book__example-press__2025-06-01.txt
原文语料/video__example-channel__2026-02-10.txt
原文语料/article__example-blog__2026-01-01__02.txt   ← 同一天第二篇
```

## 字符集

只允许：小写字母、数字、短横线 `-`、下划线 `_`、点 `.`。
不允许空格、中文、括号。中文标题的原文，来源名用拼音或英文代号。

## 禁止事项

- 禁止入库后重命名：文件名即身份，重命名会破坏来源标注。
- 禁止同一文件名覆盖：重名文件必须加序号另存。
- 日期用材料本身的日期，不用入库日期（入库日期记在收件登记里）。
