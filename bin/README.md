# bin/

## kb-search.sh —— 通用关键词检索

主题知识库的全文检索工具（第三层检索，前两层是概念索引→主题索引）。

### 用法

```bash
./bin/kb-search.sh "关键词"            # 全库检索（主库在前，备用库在后）
./bin/kb-search.sh "关键词" 知识库/    # 只检索指定目录
```

### 输入输出约定

- 输入：`$1` 关键词（必填，支持 grep 正则）；`$2` 起始目录（可选）。
- 输出：按目录分组，每行 `文件路径:行号:行内容`；
  默认范围的分组标签为【主库】/【备选库·仅作参考】。
- `README.md` 占位文件不参与检索（自动排除）。
- 退出码：0 = 有命中；1 = 无命中；2 = 用法错误（缺关键词/目录不存在）。

### 规则

- 检索前先走三层检索顺序（`规则/检索规范.md`），不要跳过索引。
- 结果引用时按 `规则/来源标注规范.md` 注明出处。
