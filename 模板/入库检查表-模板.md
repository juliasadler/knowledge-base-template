# 入库检查表（模板）

> 使用方法：每次入库复制一份，改名为 `清单/入库检查-YYYYMMDD.md`，
> 逐项打勾。对应 `规则/入库SOP.md` 七步。

批次日期：YYYY-MM-DD
材料标题：________________
来源：________________

## 第一步：收件

- [ ] 已登记到 `清单/收件登记.md`（日期、标题、来源、类型）
- [ ] 确认非重复收件

## 第二步：完整性预检（质量门①）

- [ ] 格式可读（无乱码）
- [ ] 来源明确
- [ ] 日期明确
- [ ] 不满足 → 已打回，未进入第三步

## 第三步：保存原件

- [ ] 文件名符合 `规则/语料命名规范.md`
- [ ] 已存入 `原文语料/`，未编辑、未重命名
- [ ] 新来源已登记到 `清单/来源清单.md`

## 第四步：归类（质量门②）

- [ ] 已判定主题/板块：________________
- [ ] MECE 检查通过（能归入现有主题 / 已新增主题并更新主题索引）
- [ ] 无法归类 → 已进 `备用库/`，未硬塞

## 第五步：提炼（质量门③）

- [ ] 已去重（无重复原子）
- [ ] 原子条目字段齐全（`规则/原子条目规范.md`）
- [ ] 每条知识已标注来源（`规则/来源标注规范.md`）
- [ ] 提炼文档已存入 `知识库/`

## 第六步：更新索引

- [ ] 总索引已更新
- [ ] 主题索引已更新
- [ ] 概念索引已更新（如有新概念）
- [ ] 原子映射表已更新

## 第七步：交叉引用检查

- [ ] 新条目与已有条目的引用双向可达
- [ ] 矛盾观点已双方保留并标注来源

## 第八步：版本记录

- [ ] 更新日志已记一笔
- [ ] 相关文档 version 已 ＋1

检查人：________________
