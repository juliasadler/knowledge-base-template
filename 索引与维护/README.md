# 索引与维护/

三层索引 ＋ SOP执行记录 ＋ 更新日志 ＋ 监控方法的存放区。

## 文件清单

| 文件 | 从哪来 | 何时更新 |
|---|---|---|
| 总索引.md | 复制 `模板/总索引-模板.md` | 每次文档增删/变更 |
| 主题索引.md | 复制 `模板/主题索引-模板.md` | 每次入库、主题增删 |
| 概念索引.md | 复制 `模板/概念索引-模板.md` | 每次入库（有新概念时） |
| 原子映射表.md | 新建 | 每次原子增删（`规则/原子条目规范.md`） |
| 更新日志.md | 复制 `模板/更新日志-模板.md` | 每次入库/转正/审计（`规则/更新日志规范.md`） |
| 增量监控方法.md | 按需新建 | 监控到新内容时的判定与补齐流程 |

## 规则

- 索引与内容不一致视为故障，每月复盘全量对账一次
- 索引文件只登记、只导航，不写正文
